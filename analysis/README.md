# Analysis & Comparative Frameworks

## Overview
This directory houses analytical comparisons between the Scalar Relaxation Cosmology (SRC) / Dynamic Fluid Medium (DFM) framework and conventional physics paradigms (General Relativity, Standard Model), as well as ongoing theoretical burdens and open questions.

## Subdirectory Structure
- `conventional-physics-comparison.md` — Direct juxtaposition of assumptions, mechanisms, and explanatory limits between SRC/DFM and mainstream consensus.
- `open-questions.md` — Catalog of unresolved theoretical hurdles, mathematical gaps, and areas requiring deeper empirical modeling.
